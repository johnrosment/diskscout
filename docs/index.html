What the Labels Mean

Every file gets classified so you know what you're looking at.



KEEP

System or app file. Deleting it could break your Mac or an app. Don't touch it.

✂

✂ CLEANUP

Cache, build artifact, or temp file. Safe to delete — it will regenerate or can be reinstalled.

💤

💤 STALE

Hasn't been modified in over 6 months. Review whether you still need it.

3 Usage & Examples

Run with different flags to customize your scan.

Terminal
# Top 50 largest files (default) $ diskscout # Top 20 largest, then pick any to open in Finder $ diskscout -n 20 -o # Only scan your Downloads folder $ diskscout -p ~/Downloads # Only show files over 1 GB $ diskscout -m 1G # Scan your home folder, include hidden files $ diskscout -p ~ -a # Include system directories too $ diskscout -s # Export to CSV for a spreadsheet $ diskscout -c > big-files.csv # Combine: top 30 over 500MB, reveal in Finder $ diskscout -n 30 -m 500M -o

FAQ

Will this delete my files?

No. DiskScout is 100% read-only. It will never delete, move, or modify any file on your system. It only reads file sizes and paths.

Why does the scan take a while?

Scanning your entire drive means walking every file. Use -p ~/Downloads to scan a specific folder, or -m 500M to skip small files.

What does "stale" mean?

A file marked stale hasn't been modified in 6+ months. It might still be important — it's just a heads-up to review it.

How do I open a file's location in Finder?

Run with the -o flag. After the scan, type a result number and it opens that file's folder in Finder with the file highlighted.

I get "permission denied" errors.

Some system folders require elevated access. The script skips them by default. If you want a full scan including system dirs, run with -s and prefix with sudo.
